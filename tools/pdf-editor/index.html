PDF Editor उपयोग करने की विधि

  1. Sign in करें और editor में PDF चुनें या drag-and-drop करें।
  2. Left sidebar से page चुनें; page rotate, reorder, delete या blank page जोड़ें।
  3. Toolbar से text, image, shape, highlight, arrow, freehand या signature चुनें।
  4. Canvas पर content रखें और property controls से size, रंग, स्थान आदि समायोजित करें।
  5. Save PDF दबाएं, flatten विकल्प चुनें और export की हुई PDF खोलकर जाँच लें।
