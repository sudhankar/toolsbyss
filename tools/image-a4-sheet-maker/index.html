Image to A4 Sheet Maker इस्तेमाल करने की विधि

कई फोटो चुनें, ग्रिड और गैप सेट करें और A4 प्रिंट शीट बनाएं। फ़ाइलें आपके ब्राउज़र में प्रोसेस होती हैं। नीचे दिए गए चरण इसी टूल के वास्तविक काम के अनुसार हैं।

  1. वे सभी फोटो चुनें जिन्हें एक A4 sheet पर व्यवस्थित करना है।
  2. Grid में rows/columns या उपलब्ध layout विकल्प और फोटो के बीच gap तय करें।
  3. Preview में हर फोटो का आकार, क्रम और spacing देखें; जरूरत हो तो settings बदलें।
  4. A4 sheet डाउनलोड करें और print से पहले page orientation तथा print scale verify करें।

बेहतर परिणाम के लिए

  • संस्थान/आवेदन में मांगे गए size और format का पालन करें।
  • Preview में नाम, फोटो, हस्ताक्षर और spelling जाँचें।
  • किसी दूसरे व्यक्ति की फोटो/हस्ताक्षर बिना अनुमति उपयोग न करें।
