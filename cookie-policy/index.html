Cookie Policy

Authentication, session handling और भविष्य में advertising से संबंधित browser storage/cookie जानकारी।

Cookies और समान technologies

वेबसाइट cookies, session storage, in-memory state या अन्य browser mechanisms का उपयोग functionality और security बनाए रखने के लिए कर सकती है। Firebase Authentication इस site में session/tab persistence mode पर configured है ताकि tab/session समाप्त होने पर user से फिर sign in कराया जा सके।

किसलिए उपयोग होता है?

  • Authentication state और verified account session बनाए रखना।
  • 15 मिनट inactivity timeout और warning जैसी session सुविधा लागू करना।
  • कुछ tool preferences या locally saved drafts को support करना—जहाँ tool ऐसा feature देता है।
  • यदि भविष्य में ads/analytics enable किए जाते हैं तो संबंधित provider की cookies या identifiers लागू हो सकते हैं।

Third-party services

Firebase, Cloudflare, Google services, CDN libraries और enabled advertising provider अपने domain/storage mechanisms इस्तेमाल कर सकते हैं। उनकी policies अलग लागू होती हैं।

आपके विकल्प

आप browser settings से cookies/storage clear या restrict कर सकते हैं। ऐसा करने पर sign-in, session continuity या कुछ tool features काम करना बंद कर सकते हैं। केवल page reload करना हर provider की stored state को clear नहीं करता।
