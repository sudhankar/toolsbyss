Government document photos: prepare a compliant image

A practical checklist for passport-style photos and signatures.

Practical guide · Updated November 2026

Read the portal requirement

Confirm exact dimensions, background, file type, size limit and whether the portal accepts colour or grayscale.

Use even lighting

Keep the subject centred, background plain and image sharp. Avoid filters and heavy retouching.

Crop carefully

Use a crop tool to meet the required aspect ratio, then resize to the exact pixels if specified.

Check the final file

Verify the file size, dimensions, file type and face/signature visibility before uploading to the official portal.
