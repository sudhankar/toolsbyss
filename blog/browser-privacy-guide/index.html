Browser privacy and file safety

Know what local browser processing means and what it does not mean.

Practical guide · Updated November 2026

Local processing

Some ToolsBySS utilities process selected files inside the browser, so the source file does not need to be uploaded to a ToolsBySS file-processing server. This depends on the individual tool implementation.

Third-party resources

The website can load libraries, authentication services, ads or other third-party resources. Read the Privacy Policy and tool-specific notes to understand those data flows.

Protect downloads

Your browser download folder may be accessible to other people using the same device. Remove sensitive copies when appropriate and avoid shared/public devices.

Verify before sharing

Open the final file, check the content and metadata where relevant, and share only with intended recipients.

Explore related tools

Visit the All Tools directory or browse PDF, image, financial and office collections. For account and data practices, read the Privacy Policy.
