PDF Editor: a practical step-by-step guide

Learn how to open a PDF, arrange pages, add annotations and export a checked copy.

Practical guide · Updated November 2026

What this editor can do

Use the editor to place new text boxes, images, shapes, highlights, arrows, freehand marks and signatures over a PDF. You can also rotate, reorder, delete, add or combine pages.

What it cannot do

It does not reliably rewrite text objects that were already embedded in the original PDF. For a source document you own, edit the original Word or design file and export a fresh PDF whenever possible.

Step-by-step workflow

Sign in with a verified email. Open the PDF in the editor. Select a page from the thumbnail rail. Choose a tool from the toolbar and place content on the canvas. Adjust the properties, preview all pages, then save/export. Reopen the exported file to check layout and legibility.

Privacy checklist

Use a trusted device, avoid public computers for confidential files, and verify the downloaded copy before sharing. Browser processing does not remove the need to protect your local device and downloads.
