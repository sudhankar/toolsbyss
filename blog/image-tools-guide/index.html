Image tools: resize, compress and convert

Choose image operations that preserve the dimensions and quality you need.

Practical guide · Updated November 2026

Start with the target

Before editing, find out the required pixel dimensions, file format, maximum file size and whether transparency is needed.

Resize versus crop

Resize changes the image dimensions. Crop removes parts of the image. Use crop only when the subject can safely lose surrounding content.

Choose the format

PNG is useful for sharp graphics and transparency; JPEG is widely compatible for photographs; WebP can reduce size where supported. Always keep an original copy.

Check the export

Open the final image at actual size and check text, edges, colour and file extension before using it.
