Frequently Asked Questions

ToolsBySS account, tools, files, privacy और financial estimates के सामान्य प्रश्न।

क्या tools इस्तेमाल करने के लिए account चाहिए?

Tool pages और guides की instructions पढ़ी जा सकती हैं। Interactive tool interface खोलने के लिए verified email से sign in आवश्यक है।

क्या signup मुफ्त है?

Email/password Firebase Authentication के no-cost usage limits के भीतर चल सकता है। Provider quotas, future product changes या अतिरिक्त paid services अलग हो सकती हैं। Site owner को केवल जरूरी होने पर ही paid plan चुनना चाहिए।

क्या files server पर upload होती हैं?

यह हर tool पर निर्भर है। कुछ tools browser/local processing के लिए बने हैं; कुछ third-party libraries/services से संपर्क कर सकते हैं। प्रत्येक page का privacy note पढ़ें और sensitive file से पहले verify करें।

Login session कब खत्म होता है?

Site config में 15 मिनट inactivity timeout सेट है और उससे पहले warning दिखाई जा सकती है। Browser/tab बंद होने पर session persistence समाप्त हो सकती है। Network loss की स्थिति में final logout event छूट सकता है।

कौन-सा email activity sheet में दर्ज होगा?

यदि Google Sheets logging configured और enabled है, तो verified Firebase UID/email, timestamps, events और tool identifiers owner-controlled spreadsheet में record किए जा सकते हैं। Sheet public नहीं होनी चाहिए।

क्या PDF Editor मौजूदा text बदलता है?

यह editor नए text, images, shapes और annotations overlays जोड़ता है। Existing PDF text को विश्वसनीय रूप से rewrite नहीं करता। Secure redaction भी इसका विकल्प नहीं है।

क्या financial calculator का result guaranteed है?

नहीं। Output user-supplied assumptions से निकला estimate है। Current rate, tax, fees और official conditions अलग से जाँचें।

क्या AdSense approval निश्चित है?

नहीं। Google review, site quality, original content, navigation, policies और eligibility के आधार पर निर्णय करता है। कोई page या design approval की guarantee नहीं देता।

समस्या या correction कहाँ भेजें?

Contact page पर दिए email पर exact URL और समस्या भेजें। Password/OTP कभी न भेजें।
