Privacy Policy

ToolsBySS uses Firebase Authentication when enabled to create and manage accounts. We may process account email, Firebase user identifier, email-verification status, session start/end events, tools used and approximate session duration for service operation, security and usage records. Activity logs are sent through a Cloudflare Pages Function to a Google Sheet controlled by the site owner. Browser tools may process files locally, but individual tools and third-party libraries may have different network behaviour; review each tool’s note and avoid confidential files on shared devices. Third-party services may include Firebase, Google Sheets/Apps Script, Google Fonts, CDN-hosted libraries and, if enabled, advertising providers. The site owner must configure retention, access controls and applicable legal compliance for those services. We do not ask users to submit passwords, OTPs or payment credentials to ToolsBySS. Contact the configured site email for access, correction or deletion requests.
