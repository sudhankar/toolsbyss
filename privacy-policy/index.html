Privacy Policy

यह नीति बताती है कि ToolsBySS account, session activity, tool usage और browser data को किस प्रकार संभालता है।

1. यह नीति किस पर लागू है?

यह नीति ToolsBySS वेबसाइट, sign-in flow, tool pages, guides और उनसे जुड़ी साइट सेवाओं पर लागू होती है। कुछ tools browser में file processing करते हैं; कुछ third-party JavaScript libraries या online services पर निर्भर हो सकते हैं। हर tool का data behaviour समान नहीं माना जाना चाहिए।

2. Account और authentication data

Account बनाने और sign in करने के लिए Firebase Authentication का उपयोग किया जाता है। इससे आपका email address, Firebase user identifier (UID), email verification status और authentication/session से जुड़ी तकनीकी जानकारी process हो सकती है। ToolsBySS आपके account password को अपने Google Sheet में लिखने के लिए design नहीं किया गया है। Password Firebase Authentication संभालता है।

3. Session और tool activity logging

साइट session start, sign-out/session-expiry और tool-open जैसे activity events को same-origin Cloudflare Pages Function पर भेज सकती है। जब site owner Google Apps Script/Google Sheets logging को configure और enable करेगा, तब verified Firebase ID token से सत्यापित UID/email, event name, tool identifier, event timestamp और session duration owner-controlled Google Sheet में दर्ज हो सकते हैं। Sheet को public share नहीं किया जाना चाहिए। Logging endpoint या sheet configuration बदलने पर इस नीति को फिर से जाँचना चाहिए।

Browser बंद होने, network disconnect होने या device crash होने पर logout event तत्काल दर्ज न हो पाए; अगली सफल login पर पिछला open session बंद किया जा सकता है। इसलिए session duration अनुमानित हो सकती है।

4. Files और user-provided content

Tool implementation के अनुसार files browser में process हो सकती हैं या third-party library/service से संपर्क कर सकती हैं। किसी भी tool को universally offline या universally server-free नहीं माना जाना चाहिए। Tool page का privacy note पढ़ें, छोटी sample file से परीक्षण करें और अत्यधिक confidential file को shared/public device पर न खोलें। ToolsBySS को tool input में password, OTP या bank credentials देने की आवश्यकता नहीं है।

5. Service providers और third parties

साइट संचालन में Firebase Authentication, Cloudflare Pages/Functions, Google Apps Script/Sheets (यदि activity logging enabled हो), CDN-hosted libraries, Google Fonts और भविष्य में enabled advertising provider शामिल हो सकते हैं। इन सेवाओं का अपना data handling, security और retention policy होता है। हम third-party provider की स्वतंत्र policy को नियंत्रित नहीं करते।

6. Analytics और advertising

Firebase project को Google Analytics property से जोड़ा गया हो सकता है, लेकिन वेबसाइट के वर्तमान page source में Google Analytics measurement tag/SDK शामिल नहीं है। यदि भविष्य में analytics tracking जोड़ी जाती है तो इस नीति को update किया जाएगा। फिलहाल site-wide advertising mode default रूप से off है। AdSense या अन्य ads चालू किए जाने पर advertising cookies, identifiers, consent और provider disclosures लागू हो सकते हैं।

7. Cookies, session storage और security

Firebase Authentication इस वेबसाइट में tab/session-based persistence के लिए सेट है। Browser storage/session mechanisms login state और session continuity में मदद करते हैं। Idle timeout configuration के अनुसार inactive session समाप्त किया जा सकता है। Browser settings या strict privacy extensions कुछ functions रोक सकते हैं।

8. Retention और deletion

Account और activity records उतनी अवधि तक रखे जा सकते हैं जितनी service operation, security, troubleshooting या legal obligations के लिए आवश्यक हो। Google Sheet logging enable होने के बाद owner को access सीमित और retention schedule तय रखना चाहिए। Account या activity deletion के लिए registered email से Data Deletion page पर दिए निर्देशों के अनुसार संपर्क करें।

9. बच्चों और संवेदनशील जानकारी

किसी अन्य व्यक्ति की निजी जानकारी बिना अनुमति दर्ज न करें। Minor users को parent/guardian की देखरेख में सेवा उपयोग करनी चाहिए। Site पर passwords, OTPs, payment credentials या sensitive identity documents ईमेल से न भेजें।
